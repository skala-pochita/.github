## 🛡️ SentraAI

AI 에이전트 프로젝트를 업로드하면 **코드 취약점과 도구 권한을 검사**하고, **격리 환경에서 공격을 실행**해 결과를 확인합니다.
발견한 문제는 **국내 AI 법령·가이드라인 원문과 연결**해, 추가로 검토해야 할 항목과 근거를 보고서로 제공합니다.

| | |
|---|---|
| 🔍 **정적 감사** | 코드 취약점 · 비밀값 노출 · 에이전트 도구 권한 점검 |
| ⚔️ **레드팀** | 프롬프트 인젝션 공격 생성 · 격리 샌드박스 실행 · 판정 |
| 📚 **규제 매핑** | 국내 AI 규제 원문을 RAG로 검색해 통제 항목과 근거 연결 |
| 📊 **보고서** | 공격 성공 경로와 관련 코드, 위험도를 시각화 |
